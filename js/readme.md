# JavaScript Guide Reference ✨

Guía de referencia rápida para JavaScript, organizada por secciones para facilitar el aprendizaje de los fundamentos del lenguaje.

## 📁 Estructura del proyecto

```
guide-reference-js/
├── public/
│   ├── index.html
│   └── sections/
│       ├── variables.js
│       ├── arrays.js
│       ├── funciones.js
│       ├── clases.js
│       └── bucles.js
└── README.md
```

## 🚀 Cómo visualizar

1. Abre `public/index.html` directamente en tu navegador.
2. O usa Live Server en VS Code (clic derecho → "Open with Live Server").

## 📚 Secciones

- `Variables` → var, let, const y asignaciones.
- `Arrays` → Arrays, objetos y estructuras anidadas.
- `Funciones` → Declaradas, anónimas, flecha.
- `Clases` → Propiedades, constructor, métodos.
- `Bucles` → for, while, do-while.

---

**Perfecta para quienes están comenzando con JavaScript o quieren una hoja de referencia organizada.**
